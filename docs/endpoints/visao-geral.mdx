# Referência de Endpoints

Esta seção é um **guia curado** dos endpoints mais usados, com exemplos prontos. Para a
lista **exaustiva e executável**, use o [Swagger](http://localhost:3333/docs).

## Convenções

- **Base URL:** `https://api.mockmerce.com.br/v1` (produção) ou `http://localhost:3333/v1` (local).
- **Headers de negócio:** `X-API-Key` (obrigatório) e `X-Student-RM` (recomendado).
- **Ações do cliente logado:** somam `Authorization: Bearer <token>`.
- **Paginação:** rotas de lista aceitam `page` e `pageSize` (máx. `100`) e devolvem
  `{ data, page, pageSize, total }`.
- **Erros:** sempre `{ "error": { "code", "message" } }`.
